# PocketSmart AI

PocketSmart AI is a GenAI-powered budget recommendation assistant.

## Features

- User registration
- User login
- Logout
- JWT-based authentication
- Session information
- Home Interior Planner
- Party Budget Planner
- Jewelry Planner
- Optional jewelry outfit image upload
- Gemini AI integration
- Fallback recommendation engine
- Recommendation history
- SQLite database
- FastAPI REST API
- Responsive frontend
- Swagger API documentation
- Automated tests
